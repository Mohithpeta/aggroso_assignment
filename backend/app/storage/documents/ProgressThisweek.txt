Project Overview
The project is focused on creating a health monitoring application that leverages Google API for user authentication and connects various health metric components (Blood Pressure, SpO2, and Weight) between the frontend and backend.

Progress Summary (Past Week)
1. Google API Integration
Implemented Google OAuth2 for Authentication:
Developed authentication routes for Google Sign-Up and Login using the Google API.
Utilized google-auth-library to verify ID tokens received from the client.
Ensured successful integration by enabling users to log in with their Google credentials, with appropriate session management.
2. Session Management
Established Secure Session Handling:
Configured express-session to manage user sessions effectively.
Set secure cookies with attributes such as expiration, HTTP-only, and secure flags to enhance user security.
Ensured that user sessions persist across multiple requests, providing a seamless experience after authentication.
3. Integration of Health Metric Components
Blood Pressure Chart (BPChart) Integration:

Developed API endpoints to fetch blood pressure data for the BPChart component.
Integrated real-time updates using Socket.io to ensure the chart reflects new entries as they are submitted.
Implemented input validation and error handling for the data submissions to maintain data integrity.
Weight Component Integration:

Established POST and GET routes for weight data management.
Integrated the Weight component with the backend, ensuring data submission reflects in the frontend component dynamically.
Utilized Socket.io to push new weight entries to connected clients in real-time.
SpO2 Component Integration:

Created similar API routes for managing SpO2 readings, mirroring the functionality of the other health metric components.
Ensured the SpO2 component is responsive to real-time data updates, enhancing the user experience by displaying the latest readings immediately.
4. Testing and Validation
Conducted Initial Testing:

Performed testing on the Google OAuth2 integration, confirming successful authentication and session management.
Validated data submission and retrieval processes for Blood Pressure, Weight, and SpO2 components to ensure all endpoints function as expected.
Ensured that real-time updates via Socket.io are operational and accurately reflect changes across connected clients.
User Input Validation:

Implemented express-validator for all relevant API routes to ensure incoming data adheres to the expected formats, enhancing reliability and user experience.
